# KindMoment Website Security

## Reporting a vulnerability

Please report suspected security or privacy issues privately to
`tokicx@gmail.com`. Include the affected page, a concise description and safe
reproduction steps. Do not include private messages, contacts or payment data.

Please do not publish sensitive vulnerability details in a public issue before
the developer has had a reasonable opportunity to investigate.

## Website security posture

- The public website contains no application source code, API keys or secrets.
- The website uses no JavaScript, analytics, advertising or third-party embeds.
- A restrictive Content Security Policy blocks scripts, network connections,
  frames and embedded objects.
- KindMoment application source code is maintained separately and is not part of
  this repository.
